# Rodies V3

Updated Rodies shoe shop.

## Changes
- Customer pages no longer show an Admin link.
- Admin access is hidden behind the three-line button in the bottom-left corner.
- Each product can have up to 6 colour photos.
- Every uploaded photo can be assigned a colour.
- Customers can click a colour and the matching photo is displayed.
- Existing products are automatically converted to the new photo format.

## GitHub Pages
Upload/replace the project files in your GitHub repository and keep GitHub Pages pointed at the `main` branch.

Note: this version stores products/photos in browser localStorage, as the original project did. For a real multi-device store, Supabase Storage/Database and proper authentication should be connected later.
